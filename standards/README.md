# Shared CDL standards in TransitGen

`AUDIO_APP_BASELINE.md` is the approved shared baseline for CDL audio applications. `HELP_DOCUMENTATION.md`, `THEME_STYLE_SPEC.md`, and `VST_PRODUCT_REQUIREMENTS.md` point to its canonical requirements. Accessibility, GUI architecture, and release guidance are provisional engineering checklists.

TransitGen's product-specific specifications remain authoritative for behavior where they add detail. Where a project specification conflicts with the approved shared baseline, resolve the conflict in the project specification and record any deferred requirement in `docs/spec/09-shared-baseline-compliance.md`.
